# Diseño UX/UI · SHURI

Diseño de interfaces del sistema SHURI (Reparaciones y Ventas), hecho en Figma por **Félix Gael Martínez Saldívar** (Frontend & UX/UI).

- Archivo en Figma: https://www.figma.com/design/wUFXid6RcC3a6H9iEdokWi/Untitled
- Marca blanca: el logo y nombre del negocio son protagonistas; SHURI aparece de forma discreta.
- Datos de ejemplo coherentes en todos los módulos (negocio de ejemplo: Rivera Cell, una sola sucursal).

## Estructura

| Carpeta | Contenido |
|---|---|
| `01-acceso/` | Inicio de sesión del personal (A.1–A.4) |
| `02-administrador/` | AD1 Inicio · AD2 Reportes · AD3 Cortes · AD4 Catálogo · AD5 Proveedores · AD6 Facturación · AD7 Usuarios · AD8 Bitácora · AD9 Configuración |
| `03-cajera/` | 01–12: apertura de caja, punto de venta, ventas, presupuestos, órdenes, entrega, inventario, clientes, estadísticas, corte, documentos impresos |
| `04-jefe-de-tecnicos/` | J1–J10: tablero, cotizar, garantías (el jefe decide si aplica), refacciones, inventario, técnicos, versión celular |
| `05-tecnico/` | T1–T7: equipos asignados, banco de trabajo, garantías, refacciones, historial, versión tablet |
| `06-portal-cliente/` | P1–P4: acceso, seguimiento de la reparación, garantía, información |
| `07-componentes/` | Componentes, tokens de color y texto, reglas de comportamiento y versión 1366 px |

Cada imagen es una sección completa de Figma con todas sus pantallas en orden.

## Tamaños base
- Escritorio 1440×900 (menú lateral de 184 px) · compacto 1366×768 (riel de 72 px)
